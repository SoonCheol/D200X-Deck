# Stream Deck 7.6.1.23033 분석 인수인계

[CLI 정적 분석 보고서](cli/StreamDeck_REA_7.6.1_Analysis.md)에는 기존 함수 주소와 고유 Evidence ID 32개를 유지했다. [데스크톱 기록](desktop/07-feature-matrix.md)은 실제 UI에서 본 항목과 당시 미확인 항목을 기록한다. [산출물 대조](desktop/rea-artifacts.md)에서 진단, 디컴파일 연결 테스트, 빈 manifest 추적 파일을 설명한다.

| 상태 | 개발에 전달할 내용 |
|---|---|
| 정적 확인 | CLI 보고서는 0x140150040의 메인 창 구성, 0x1401dcd40과 0x1401dd670의 트레이 메뉴 구성, 0x14040a0c0의 패키지 검사, 0x1404540f0의 manifest 읽기, 0x14040b8b0의 액션 순회를 기록한다. |
| UI 확인 | 한국어 메인 창의 3×5 키, 보이는 키 동작 24개, 환경설정 탭 6개, 타이머 추가·선택·삭제 흐름을 데스크톱에서 관찰했다. |
| 추정 | 시작 시 두 검색 경로가 설치본과 사용자 플러그인을 각각 로드하는 것으로 해석했다. 실제 사용자 경로와 실행 여부는 미확인이다. |
| 미완료 | 전체 메뉴 및 콜백, 액션 편집·지속화, 매니페스트 필드 기본값과 private 형식, 프로세스 실행 및 IPC, 실제 다이얼·터치 동작, OpenDeck·Ulanzi 호환성. |

메뉴 분석 시 CLI 트레이 메뉴와 데스크톱 키 우클릭 메뉴를 별개의 화면으로 다룬다. CLI 정적 경로는 실행 관측을 대신하지 않으며, Evidence ID는 원본 레코드가 보관됐다는 의미가 아니다.

비교 시점에 main은 e9354d7ced59914adb6cfd6b16962c37dd101af6, windows-port는 beda4d82c75e4762b75d56c9ed38f9f2987c1afd이었다. Windows 브랜치는 main보다 50커밋 앞서 있었고, 최신 커밋은 동작 목록 안내 문구를 수정했다. 이 문서는 main 기준이다.

공개 사본은 로컬 절대 경로를 제거했다. 원시 진단 및 디컴파일 JSON, 빈 추적 JSON, 스크린샷, Ghidra 배포본과 프로젝트, 실행 파일과 플러그인 바이너리는 로컬에 두었다. 데스크톱 기록의 스크린샷 링크는 로컬 캡처 표기로 바꿨다.
