# Stream Deck 7.6.1 (23033) 한국어 Windows — 기본 24개 키 액션 속성창 관찰

## 조사 범위와 근거

- **자료 출처:** Codex가 실제 Stream Deck 7.6.1 (23033) 한국어 Windows 앱에서 조사한 뒤 사용자가 채팅으로 전달한 결과. 이 문서는 그 보고 내용을 보존한 것이며, 이 커밋에서 별도로 GUI를 실행하거나 REA를 재분석한 것은 아니다.
- **관찰 방법:** '오디오 재생'은 기존에 배치된 키의 현재값을 읽었고, 나머지 23개 액션은 임시 프로필에 새로 배치하여 초기 표시값을 확인했다. 조사 후 임시 프로필을 삭제했다고 보고됨.
- **공통 속성창:** 액션 이름, 삭제 버튼, 아이콘 미리보기·변경 컨트롤, 제목 입력 및 제목 스타일 메뉴. 신규 배치 액션의 제목은 빈칸.
- **REA 분석에서의 관련 함수(기존 보고서 참조):** `0x1403D6AC0`이 매니페스트 `Actions` 및 `PropertyInspectorPath` 파싱, `0x14040B8B0`이 신규 액션을 등록하는 `0x14040C720` 호출. 이것만으로 내장 24개 속성창 구현 구조 전체가 판명된 것은 아니다.
- **접근성 트리에서 관찰:** 오디오 재생 속성창은 공통 `PropertyInspectorBase` 내부에 `ESDSoundboardActionSpecificView`가 있음.
- 기존 REA 보고서: [StreamDeck_REA_7.6.1_Analysis.md](../cli/StreamDeck_REA_7.6.1_Analysis.md)

## 개발 적용 시 제약

- **복제 기준:** Stream Deck 7.6.1의 사용자 인터페이스·액션 동작·속성창.
- **D200X 기존 코드 재사용 범위:** USB 연결/버튼 이벤트/화면 전송 등 **하드웨어 통신만**. 이전 Ulanzi 편집기의 UI나 액션 편집기를 재사용해 원본을 대체하지 않는다.
- 이 문서는 **관찰 보고서**이다. 구현 완료, 실행 검증, 픽셀 일치의 증거가 아니다.
