# 08. 확인하지 못한 부분

## 설치 후 관찰

설치 및 실행 문제는 해소됐다. 기기 설정에서 연결된 기기가 없다고 표시되며 물리 키, 다이얼, 터치스트립 동작을 확인하지 못했다. 창 크기별 변화, 추가 메뉴, 타이머 이외 액션의 개별 설정과 실행, 프로필·폴더·다중 동작 편집 전 과정, 플러그인 런타임과 D200X 호환성은 미확인이다. 아래 초기 조사 기록에는 설치 전 상태가 포함되어 있다.

## 초기 조사 기록과 공식 문서

## 장애 원인
1. CUA 앱 및 창 목록에 Stream Deck이 나타나지 않았고, 일반 설치 후보 경로에서 실행 파일이 발견되지 않았습니다.
2. 레지스트리 기반 설치 확인은 샌드박스 권한 거부로 수행할 수 없었습니다. 시스템 전체 미설치를 단정하지 않습니다.
3. 연결 REA의 네이티브 UI 기능은 현재 Windows가 아닌 macOS 전용으로 보고됐습니다.
4. D200X-Deck 로컬 폴더에서 확인된 것은 Test\D200X-Deck-win-x64-preview의 Electron 실행 파일입니다. 조사한 위치에서 Git 저장소나 windows-port 브랜치를 확인하지 못했습니다.

## 완료에 필요한 증거
- 앱 실행 가능 Windows 환경에서 정확한 버전, 설치 경로, exe 속성 확인
- 메인 화면, 크기 변화, 전체 메뉴/컨텍스트 메뉴 스크린샷
- 액션 목록 전체를 카테고리별로 기록하고 기본 제공/외부 plugin 출처 구분
- 모든 기본 액션의 아이콘, 속성, 키/다이얼 지원, 조건 확인
- Settings 전체 탭, 프로필·폴더, plugin 관리, Multi Action, Key Logic, Dial Stack, touchscreen UI 실제 조작
- 버튼/다이얼 등록부터 수정·삭제까지 화면 증거를 포함한 순서 기록
- D200X-Deck 소스 저장소 원격과 브랜치 경로 특정
- OpenDeck 및 Ulanzi 호환 대상 plugin/profile로 실행 시험
