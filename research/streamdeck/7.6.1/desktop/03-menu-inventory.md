# 03. 메뉴 인벤토리

## 설치 후 관찰

빈 키 우클릭 (로컬 캡처)에는 폴더 생성, 다중 동작 생성, Key Logic 동작 생성, 동작 불러오기…, 현재 배경, 파일에서 설정…이 표시된다. 타이머를 배치한 키에는 고정, 복사하기(Ctrl+C), 폴더로 이동, Key Logic으로 이동, 동작 불러오기…, 동작 내보내기…, 현재 배경, 파일에서 설정…, 삭제가 표시됐다. 이 목록은 해당 두 키 상태에서 관찰한 범위다.

## 초기 조사 기록과 공식 문서

전체 메뉴 트리는 실제 앱을 관찰하지 못해 미확인입니다. 확인된 문서상 진입점만 열거합니다.

| 표시/경로 | 문서로 확인한 기능 | 범위 |
|---|---|---|
| 기어 아이콘 → Preferences | General, Account, Profiles. 6.2 release notes에 Style 탭 추가 | 전체 탭·메뉴 미확인 |
| 상단 Marketplace 아이콘 | Marketplace를 여는 진입점 | 실제 페이지·하위 메뉴 미확인 |
| 빈 키 우클릭 → Create Multi Action | Multi Action 생성 경로 | 전체 컨텍스트 메뉴 미확인 |
| 빈 키 우클릭 또는 Multi Action 범주 → Key Logic | Stream Deck 7.0에서 안내한 경로 | 현 설치판 미확인 |
| Preferences → Profiles → 하단 화살표 → Backup All → Create Backup | 프로필 백업 절차 | 메뉴의 다른 항목 미확인 |
