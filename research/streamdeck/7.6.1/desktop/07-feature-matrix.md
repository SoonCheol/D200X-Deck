# 07. 기능 확인 매트릭스

## 설치 후 관찰

| 항목 | 설치 후 확인 결과 |
|---|---|
| 버전·경로 | 7.6.1 (23033), StreamDeck.exe |
| 메인 화면·키·검색 | 3×5 캔버스, 페이지 컨트롤, 오른쪽 키/플러그인 탭과 타이머 검색 확인 |
| 메뉴·환경설정 | 빈 키와 타이머 키 우클릭 메뉴 및 설정 탭 6개 확인 |
| 액션 | 화면에 표시된 키 동작 24개 확인. 타이머 배치와 삭제 재현 |
| 추가 확인 필요 | 창 크기별 변화, 액션별 세부 속성, 실제 다이얼/터치, 플러그인 통신과 호환성, 나머지 편집 흐름 |

## 초기 조사 기록과 공식 문서

상태: 확인=명시적 자료에서 확인, 부분=일부 사실만 확인, 미확인=앱에서 검증하지 못함.

| 기능 | 상태 | 결과 |
|---|---|---|
| 설치 버전·경로 | 미확인 | 실행 파일 미발견 |
| REA 연결 | 확인 | 도구 연결됨, 세션 target은 열리지 않음 |
| Windows UI 캡처 | 제한 | REA 네이티브 UI provider는 macOS용. CUA 앱 인벤토리에 Stream Deck 없음 |
| 전체 UI/창 크기 변화 | 미확인 | 실제 화면 없음 |
| 전체 메뉴 | 미확인 | 문서상 진입점 일부만 기록 |
| 기본 액션 전체 | 미확인 | System 문서의 8개 이름만 확인, 전체성은 미보장 |
| 개별 액션 아이콘·옵션 | 부분 | 공식 문서 텍스트 일부; 화면과 아이콘 형태 미확인 |
| 검색 | 미확인 | 미관찰 |
| 이름·아이콘 변경 | 부분 | Manifest와 SDK의 상태/이미지/제목 모델 확인, 조작 UI 미확인 |
| Profiles/Backup | 부분 | Preferences 탭 및 공식 백업 순서 확인, 직접 조작 미확인 |
| 폴더 | 부분 | 프로필 구조와 Open의 폴더 대상은 문서에 등장; 편집 절차 미확인 |
| Multi Action·Key Logic | 부분 | 공식 생성/개념 문서 확인, 편집 UI 미확인 |
| 플러그인 관리 | 부분 | Marketplace 진입 문서 확인, 설치/관리 화면과 파일 경로 미확인 |
| plugin architecture | 부분 | manifest, Inspector, Node.js, WebSocket 공개 SDK 확인 |
| 다이얼·터치스크린 | 부분 | Encoder/layout/trigger metadata 확인, 앱 UI 미확인 |
| OpenDeck/Ulanzi 호환 | 미확인 | 시험하지 않음 |
| D200X-Deck Git branch | 미확인 | 찾은 것은 preview 배포 파일, source repo/branch 미발견 |
| 실제 스크린샷 | 미확인 | 캡처 불가 |

개발 판단에 쓸 수 있는 관찰은 plugin 공개 SDK 인터페이스뿐입니다. 앱 UI 충실도, 기본 액션의 빠짐없는 재현 및 호환성 승인에 필요한 근거는 확보되지 않았습니다.
