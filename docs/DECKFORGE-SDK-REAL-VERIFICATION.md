# DeckForge SDK 실제 환경 검증 체크리스트

> 2026-11-28 · 2.0.176 후보. 아래는 검증 계획이며 실제 성공 기록이 아니다. SDK 1.0 선언은 실기 결과 확인 후 판단한다.

## 준비
- 실제 설치 버전/소스 SHA/Windows 빌드 번호, D200X 연결 방식, 플러그인 버전, 앱 버전 기록. 기존 정상 프로필을 변경하지 말고 별도 시험 프로필과 시험용 파일/기기 사용. 원본 플러그인 파일 및 실제 사용자 설정 보존.
- 자동 검증과 실기 증거 구분. 토큰/암호/원본 데이터/개인정보는 로그·스크린샷 공유 제외. 시험 전후 기존 기능 비교. 실제 장비 접근 불가 시 미검증 유지.

| 검증 | 시험 및 통과 조건 | 상태 |
|---|---|---|
| Excel/COM | 설치된 Excel의 시험 통합 문서에서 읽기·쓰기·결과 표시, 오류 및 앱 종료 후 자원 정리; 실제 파일 원본 미변경 | 미검증 |

| Home Assistant | 기존 주소/토큰 유지, 시험용 스위치/센서 상태·명령 반영, 연결 중단/재연결 및 다중 상태 표시; 토큰 로그 미노출 | 미검증 |

## 판정
- 각 시험은 버전/일시/시험 조건/관찰 결과/오류/재현 절차를 남긴다. 자동 시험과 동일하다고 실기 통과 처리하지 않는다.
- 실패 시 해당 경로만 집중 수정 및 재검증. USB KEY 부분 전송은 기존 실기 게이트 유지, Model 5 기본 OFF. 비공개 외부 API는 실제 근거 확보 후 별도 판단.
- 실제 환경 확인 전 SDK 1.0 정식 선언 및 미검증 기능의 성공 선언 금지.
