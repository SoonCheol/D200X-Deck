# DeckForge 버전별 변경사항

버전별 주요 변경점을 쉽게 설명하는 페이지입니다. DeckForge의 **설정 → 버전별 변경사항 보기**에서 열 수 있습니다.

## 1.1.105 — Fusion 명령 관리자 검색과 표시 언어

### 개선
- 검색창과 **전체 찾기** 버튼을 메뉴 탭 위쪽으로 옮겼습니다.
- 검색창 오른쪽에 **한국어 / English** 선택 버튼을 추가했습니다.
- 영문명이 저장된 명령·메뉴는 선택한 언어로 보여줍니다. 이름이 없는 항목은 기존 한국어 이름이 유지됩니다.
- 선택 언어는 명령 관리자를 다시 열어도 유지됩니다.

### 유지
- 기존 메뉴 순서, 명령 ID, D200X의 기존 버튼 제목·글꼴·아이콘은 변경되지 않습니다.
- 개별 D200X 버튼의 세 가지 언어 모드는 아직 구현하지 않았습니다.

## 1.1.104 — Fusion 영문 명칭 수집 준비

### 추가
- Fusion 명령 관리자에서 **영문 수집기 준비** 버튼으로 수집 프로그램을 준비합니다.
- 영어 Fusion에서 생성한 결과를 **영문명 JSON 불러오기**로 등록합니다.
- 영문 명령명 및 메뉴명을 별도 저장하고, 영문 이름 검색·상세 조회를 지원합니다.
- 설정 메뉴에서 버전별 변경사항 페이지를 열 수 있습니다.

### 유지
- 기존 한국어 메뉴 순서, 명령 ID, D200X 버튼 제목과 글꼴·아이콘·실행 동작은 변경되지 않습니다.

### 아직 지원하지 않음
- Fusion 명령 관리자와 개별 버튼의 언어 자동 전환은 추후 구현합니다.
- 영어 Fusion에서 실제 수집기를 실행하는 실기 검증은 별도입니다.

## 1.1.103 — DeckForge 전용 플러그인 패키지

### 추가
- DeckForge 자체 패키지 **.deckforgePlugin** 설치를 지원합니다.
- 기존 **.sdPlugin** 폴더를 DeckForge 전용 설치 파일로 저장할 수 있습니다.

### 유지
- 기존 Stream Deck 플러그인 호환 방식은 유지합니다.
- Ulanzi 플러그인 자동 변환은 아직 지원하지 않습니다.

## 1.1.102 — 길게 누르기 및 업데이트 확인

### 수정
- 독립 길게 누르기 해제 시 다른 프로그램이 잘못 실행되던 문제를 수정했습니다.

### 추가
- 설치된 버전과 최신 성공 빌드 버전을 표시합니다.
- 설치할 수 있는 새 버전이 있을 때 **업데이트** 버튼이 활성화됩니다.

---

이 문서는 사용자가 쉽게 확인할 수 있는 주요 변경사항 요약이며, 빌드 및 D200X 실기 검증 여부와는 구분합니다.
