## 1. 판정 원칙 및 개발 경계

- **[코드]** 최신 소스/자동 검사에서 실행·저장·렌더링 경로가 확인됨. **[자동]** CI 또는 Windows 빌드 성공. **[실기]** 사용자 Windows GUI/물리 D200X에서 해당 조건으로 직접 확인됨. **[부분]** 일부만 구현/검증됨. **[보류]** 사용자 별도 지시까지 개발하지 않음. 코드 구현·패키징 성공을 실기 완료로 표기하지 않는다.
- 기본 기준은 **Elgato Stream Deck 7.6.1 (23033) 한국어 Windows UI**와 **Ulanzi D200X**. 일반 키 13·와이드 1·측면 키 2·노브 3, 기존 승인된 레이아웃·고정 데이터 스키마·플러그인과 HID 전송을 보존한다.
- 오직 `SoonCheol/D200X-Deck`의 `codex/streamdeck-761-clean-editor` 브랜치 사용. **PR #5 Draft·미병합 유지**. 다른 브랜치 생성, 기존 정상 UI 변경, 무관한 리팩터링 및 사용자 지시 없는 코드 수정/빌드/병합 금지.
- 이전 자료와 충돌 시 **최신 코드 → 현재 통합 상태표 → 최신 Actions → 제한된 범위의 실기 보고 → 과거 기록** 순으로 해석. 원본 GUI/공식 문서·커뮤니티 사례·D200X 실물 증거를 구분한다.

## 3. 현재 개발·검증 우선순위

### P0 — 데이터 보호 및 기존 정상 기능 회귀

- [ ] **최신 설치본 사용자 데이터 보존 검증:** `%APPDATA%\DeckForge\Profiles\profiles.json`, `.bak`, `Resources\Icons`, `Resources\IconPacks`, `Plugins`의 실제 저장·복원·업데이트/제거 시 보존. 구형 localStorage **자동 이관은 사용자 승인에 따라 의도적으로 생략**하므로, 보관 데이터를 임의로 자동 이전하거나 덮어쓰지 않는다.
- [ ] **실제 Windows 설치/제거:** 설치형 NSIS의 ‘사용자 데이터 제거’ 명시적 선택 여부, 선택하지 않았을 때 완전 보존, 포터블 시작·종료·트레이.
- [ ] **기기 통신:** USB 연결/재연결·5초 유지통신·10분 이상 동작·밝기 안전 하한·장치 화면 복원; 화면 전송이 키/노브 입력을 막거나 구형 페이지 할당을 잃지 않는지 확인.
- [ ] **저장 실패/오류 처리:** 파일 권한·손상·디스크 오류 시 기존 프로필 보존, 사용자에게 실패 안내, 반복 연타·비동기 전송으로 구형 이미지가 덮이는지 검사. 과거 C1은 코드 보정되어 **미착수로 되돌리지 않음**.

### P1 — 기본 액션·하드웨어 완성

- [ ] **원본 24개 액션 속성/우클릭 완전 대조:** 실제 속성·조건부 옵션·기본값·저장과 다시 시작·미지원 기능 사유 기록. 원본 7.6.1의 모든 메뉴·초기값을 추측하지 않는다.
- [ ] **Multi/스위치/Random/Key Logic 최종 검증:** 순서 편집, 상태별 제목/이미지, 실행 계획과 오류/취소, 지연·동시 재입력, 원본 간격 설정의 불일치(2~100ms/2~200ms)는 직접 관찰 전 미확정. 물리 Key Logic single/double/hold 타이밍 별도 실측.
- [ ] **노브·측면 키:** 실제 CW/CCW·누름·놓음·누른 채 회전의 HID 지원 확인, 1/2/5/10 단계 및 반전, 빠른 회전 시 순서·누락. PowerShell/OS 대상 앱 동작 지연은 재현 후에만 최적화.
- [ ] **Windows 앱별 실행:** 음량·음소거·가상 데스크톱·확대축소·스크롤·단축키 전환·텍스트/클립보드·파일/앱 실행·프로그램 종료, 타이머 사운드·오디오 출력 장치·페이드 등 현재 부분 또는 실기 미검증 옵션. 버튼의 `▶ 실행 테스트`와 물리 입력 결과를 구별한다.
- [ ] **폴더·프로필 고급 동작:** 자동 폴더 종료가 ‘진입 후’가 아닌 **액션 실행 후** 시작하는지 확인, 0~60초와 즉시 복귀, 액션별 예외, 프로필별 고정 상속·실시간 갱신, Smart Profile 최소화 중만 작동. 신규 10페이지 제한과 구형 128페이지 자료는 무손실 처리.
- [ ] **Key Up/Down과 상태형 예외 실기:** 일반 순간형/Fusion은 누름/뗌 시 이미지만 전환, HA/SDK 실제 ON/OFF·Multi Switch·타이머·Key Logic 상태는 임의 복귀 금지; 빠른 페이지 전환 후 눌림 이미지 잔류/오염 방지. 표시 전용 `indicator`, 와이드 특수 화면 제외.
- [ ] **와이드 화면:** 네이티브 시계·날짜/CPU·RAM·GPU·노브 정보 모드의 1회 입력 순환/겹침, 일반 액션 드롭 금지, 노브 3개·측면 버튼 우클릭 삭제 검증.

### P2 — 사용자 승인 UI·아이콘 라이브러리 검증

- [ ] 최신 **98px 대표 미리보기 + 상태 카드 2개 가변 정사각형** 한 줄, 간격 12px, 화면 최소 1180×800/960×630 및 100/125% 배율에서 수평 스크롤·잘림 확인. 과거 196px 고정 카드 규격을 최신 승인 예외에 강제하지 않는다.
- [ ] 각 상태 제목 입력·체크박스·`T⌄` 팝오버, **각자 활성/둘 중 하나만 활성/둘 다 해제** 시 제목/스타일 합성, 재클릭 토글·바깥 닫기·취소/저장·비편집 시 dirty 플래그 없음 확인. 기존 SDK `setTitle` 보존.
- [ ] Fluent UI + **DeckForge IoT Icons (Airburst, 106개)** + 사용자 추가 팩 공존, 검색·이미지 선택·OFF/ON 자동 매칭, 원본 파일/클립보드 가져오기, 사용자 팩 삭제 시 기본 팩 보호·기존 프로필 아이콘 복구.
- [ ] Pretendard/Noto 기호 내장 글꼴의 실제 Windows 렌더링·D200X 제목 크기/잘림, 사용자 글꼴 선택 보존; 승인된 13px UI를 임의 변경하지 않는다.
- [ ] 오른쪽 `기본 액션` 탭과 `D200X 장치·화면` 최상단 순서, 액션 패널 테마/개별 이미지 설정이 기존 키 설정을 건드리지 않는지 확인.

### P3 — Stream Deck SDK·HA·Autodesk Fusion 기능

- [ ] **SDK 실행 호환성:** HTML/Node 플러그인, 설치·압축·WebSocket·원본 Property Inspector, 설정 저장/복원, `setImage/setTitle/setState`, 종료/재시작·에러 경계 테스트. 일부 SDK 자동 프로토콜 검증이 **모든 플러그인 호환 보장**은 아님.
- [ ] **HA 실제 상태**: 엔티티 토글, 웹소켓/상태 동기화 지원 범위, OFF/ON 이미지와 상태별 제목이 실제 장치 상태와 일치하는지, 물리 키/노브/프로필 전환 후 보존 여부 확인.
- [ ] **Fusion 360**: 실제 메뉴 계층(스케치→솔리드→곡면→메쉬→판금→플라스틱→관리→유틸리티→자동화), Command Manager UI, 원본 애드인 건강 확인, 명령 드래그 아이콘 UUID/캐시/연결 끊김 X 상태, 실행과 아이콘의 교차 대입·타이밍 경합 확인. 실제 명령 실행 가능성은 메뉴에 존재한다는 사실과 구분.
- [ ] 범용 플러그인 마켓플레이스/변환기는 **호환성과 사용 필요성·별도 사용자 승인** 후 검토. 과거 ‘플러그인을 아직 시작하지 않음’이라는 계획은 적용하지 않는다.

## 4. 명시적으로 보류 중인 기능 (사용자 승인 전 착수 금지)

- **Virtual Stream Deck** 실제 기능 개발.
- **Elgato 원본 `.streamDeckProfile` 가져오기**: DeckForge JSON 가져오기는 별도 기존 기능. 공식 원본 포맷을 검증해 새 프로필로 비파괴 매핑(아이콘·제목·폰트·플러그인·페이지/노브), 미지원 내용의 경고 및 사전 미리보기를 제공하는 일은 후순위.
- Ulanzi 독자 플러그인/테마팩 로더, 앱별 동작 전체 자동화, 기존 디자인에 영향 큰 재설계 — 별도 범위 확정 전 개발 금지.
- 과거 보관 자료 및 미완료 조사 문서의 **참고 링크가 있다는 이유만으로** 새 기능을 구현하지 않는다.

## 5. 작업 완료 판정·보고 규칙
