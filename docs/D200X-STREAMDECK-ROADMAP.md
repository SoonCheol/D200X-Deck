- [ ] 4. 동적 속성창(현재 선언형 schema 지원).
- [ ] 5·6. 플러그인 공동 자원 및 다중 버튼 상태 동기화.
- [ ] 7~9. 시스템 이벤트 구독, 내장 액션 호출, 실행 결과 이벤트.
- [ ] 10~12. 동적 이미지 확대, 지속 와이드 대시보드, 추가 인증(OAuth/API key/Basic).
- [ ] 13~20. 플러그인 간 통신, 효과음, 알림, 제한 파일 저장, 추가 애니메이션, 다국어, 디버그 및 TS 도구. 필요성 검토 후 착수.

- [ ] 독자 SDK 최종 실기: HA 플러그인으로 전등 제어, 외부 상태 변화, 페이지 전환, 재연결, 절전/복귀, 다중 버튼 상태 확인. 실제 D200X/Windows 실행과 자동 검사 구분.
- [ ] Fusion 실기/Smart Profile·명령 캐시/연결·실행 교차 검증. 기존 정상 동작 재검사 반복 금지.

## 기타 잔여 검증
- 데이터 보존/복원/설치·제거, USB/HID·저장 실패 대응, 기본 액션 및 물리 입력, 상태형 이미지, 와이드/노브, UI/아이콘/폰트. 상세 [데이터·기능 보호 계약](DECKFORGE-DATA-CONTRACT.md), [UI 계약](DECKFORGE-UI-CONTRACT.md).
- Google OAuth 정식 게시·정책, 장기 보관/백업 세부 검증은 별도 승인/설정 단계. 기존 백업/복원 기능 재구현 금지.
- POP 프로그램 인식형 메뉴는 목표 등록, 미착수: [기술 분석](DECKFORGE-CONTEXT-POP-FEASIBILITY.md). 별도 지시 전 개발 금지.

## 보류 (별도 승인)
- Virtual Stream Deck, Elgato 원본 .streamDeckProfile 가져오기, Ulanzi 독자 로더/테마팩, 앱별 전체 자동화, 큰 UI 재설계.
- NAS/Google Drive/OneDrive 플러그인 저장소와 웹스토어·장기 배포 체계. 기존 호환 설치 지원은 유지.
