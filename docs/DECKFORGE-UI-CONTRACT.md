# DeckForge 전체 UI·레이아웃 단일 기준

> 2026-11-21 사용자 승인 규칙 및 현재 코드 기준의 **화면 보존 계약·문서 목차**. 소스 수정/Windows 빌드/실기 완료 보고가 아니다.
>
> 저장소: SoonCheol/D200X-Deck · 개발 브랜치: codex/streamdeck-761-clean-editor

## 2026-11-21 최종 확정: 속성창 영역 A / B / C / D / F

- **A — 기존 상단 제목·헤더:** 필요한 액션 고유 화면에서만 기존 헤더를 유지하며, 비어 있는 헤더나 불필요한 물음표(`?`) 도움말 버튼을 새로 출력하지 않는다. 오른쪽 목록의 아이콘 설정·플러그인 전용 도움말은 별도 기능이다.
- **B — 누르기 탭 + 취소/저장:** `한 번 / 두 번 / 길게` 3개 탭은 **같은 너비**, 제목·액션 이름 변경 또는 선택 표시에도 폭이 바뀌지 않는다. 탭은 기존보다 **조금 낮게** 만들고 오른쪽 취소·저장 위치를 고정한다. **다른 영역 너비를 결정하지 않는다.**
- **C — 아이콘·미리보기 편집:** **B와 별개인 독립 시각 영역**이다. 왼쪽 기존 상태별 카드 2개(해당할 경우), 오른쪽 98px 미리보기·86px 이미지·실행 테스트를 유지한다. 액션 종류에 따라 내부 편집 항목이 달라져도 **C의 영역 폭·배치 기준·예약 높이는 유지**하여 누르기 탭 전환이 아이콘 카드 크기나 D의 시작 위치를 흔들지 않도록 한다. 상태 2카드가 원래 없는 액션에 가짜 카드를 만들지 않는다.
- **D — 단일 액션 설정 부모 영역:** 이전 그림의 **D와 E는 별개 상위 영역이 아니다.** 모두 **D 안의 하위 그룹**이다. `D-1 옵션`과 `D-2 액션별 상세 필드`를 필요에 따라 표시한다. 한 번에 선택된 누르기 액션 하나의 필드만 보여주고, 다른 B/C 영역 크기·위치에 영향을 주지 않는다.
- **F — 속성창 전체 외곽:** 메인 화면의 기존 영역 배치/스크롤·노브·측면 버튼·와이드 화면·특수 액션 편집기와 격리한다. B/C/D의 국소 변경을 다른 화면에 일반화하지 않는다.
- **공통 드래그 계약:** 오른쪽 기본 액션과 플러그인 목록을 **클릭만으로 등록하지 않는다**. 일반 LCD 버튼에 드롭하면 3누르기 선택 영역, 속성창의 **누르기 탭에 직접 드롭하면 그 탭**, 속성창의 **그 밖의 빈·시각·설정 영역에 드롭하면 현재 선택된 누르기**에 등록한다. 이미 등록된 동작을 교체할 때 기존 확인창 및 특수 액션 제한 유지.
- **변경 검증:** 선택된 액션 이름의 길이가 달라져도 B의 세 탭과 취소/저장의 X좌표, C의 아이콘·미리보기 기본 크기, D의 시작점이 유지되는지 확인한다. 사용자 실기 검증 전에는 확정 완료라고 쓰지 않는다.

## 1. 필독과 기준 우선순위

- 일반 개발 세션에서는 **AGENTS.md + docs/D200X-CURRENT-STATUS.md** 두 문서만 기본 확인한다. **화면·레이아웃을 다룰 때** 이 문서의 필요한 부분과 해당 editor.js/style.css만 추가 확인한다.
- 가장 최근의 **사용자 승인 사항은 목표 규칙**, 최신 브랜치의 **실제 소스는 구현 현황**이다. 문서의 과거 레이아웃과 코드가 다르면 둘을 구분한다. 구현되지 않은 목표를 이미 완성되었다고 적지 않는다.
- 오래된 보관 문서·예전 HTML 시안은 이력과 참고 자료이지 최신 레이아웃을 덮어쓰는 기준이 아니다.
- 사용자가 승인한 디자인을 임의 재설계하거나 카드를 새로 그리지 않는다. **기존 UI 컴포넌트 재사용, 요청 범위만 국소 수정**이 원칙이다.
- 신규 기능 우선순위 확인 시에만 docs/D200X-STREAMDECK-ROADMAP.md를 읽는다. 기존 정상 기능의 전수 재조사 금지.

## 페이지 번호 버튼 전용 고정 탐색 계약 (2026-11-22)

- 기존 페이지 표시 **번호·디자인·아이콘 편집·자동 추가·모든 페이지 일괄 적용**은 그대로 유지한다.
- 페이지 표시 버튼 자체는 **한 번 누르기: 홈**, **두 번 누르기: 직전 페이지**, **길게 누르기: 직전 프로필**을 전용 고정 동작으로 사용한다.
- 이 세 동작은 페이지 번호 **전용 속성창에 읽기 전용으로 표시**, 임의의 다른 액션 할당·선택지 변경은 제공하지 않는다. 이전 프로필은 기존 방문 이력으로 A↔B 왕복 가능하다.
- 기존 프로필의 옛 `indicatorDown/indicatorHold` 설정은 삭제하지 않고 보존하되, 페이지 번호 버튼의 실제 탐색 동작에서는 고정 매핑이 우선한다.
- 기존 와이드키의 덱폴더 상위 한 단계 복귀, 측면 버튼·노브·Key Logic·순차 동작의 입력 판정은 변경하지 않는다.

## 3. 일반 LCD 버튼 속성창 — 확정한 목표 레이아웃

### 3.1 탭·상단 툴바

1. **아이콘 창 바로 위 한 줄**: 왼쪽에 **한 번 누르기 / 두 번 누르기 / 길게 누르기** 탭 3개, 오른쪽에 **취소 / 저장**.
2. 탭 내부에는 **사용 체크박스·누르기 이름·등록된 액션 이름만**. 탭의 큰 액션 아이콘·1/2/3 숫자·대표 마커를 표시하지 않는다.
3. 하나의 일반 LCD 버튼에 누르기 종류별 **서로 다른 액션 하나씩**을 등록한다. 버튼 선택 시 **한 번 누르기** 탭이 기본이다.
4. 탭을 바꾸면 **선택된 액션의 기존 전체 속성창 하나만** 전환한다: 아이콘 카드, 제목·스타일, 미리보기 및 액션별 모든 설정. 다른 두 액션의 설정을 지우거나 덮어쓰지 않는다.
5. 사용 체크 해제는 그 누르기 실행만 비활성화하고 설정을 보존한다. 선택한 탭의 액션만 개별 삭제한다.
6. **의미 없는 액션 경로줄(기본 액션 › 분류 › 액션명)과 별도의 장식용 제목줄 추가 금지.** 상단 왼쪽의 불필요한 **? 도움말 버튼은 제거**하고 기존 실행 테스트와 플러그인 전용 도움말은 유지한다.
7. 일반 액션을 버튼에 드래그하면 **3갈래 임시 누르기 드롭 선택 영역**을 보여준다. 이 영역에서는 등록된 액션의 아이콘·이름 표시를 유지한다. **속성창 탭의 아이콘 금지**와 혼동하지 않는다.
8. 폴더·페이지 표시·Key Logic·순차/무작위 복합·SDK 등 특수 액션은 기존 전용 경로 유지.

### 3.2 아이콘 2장과 미리보기

- **좌측 상태별 아이콘 카드 2개 → 우측 미리보기**의 한 줄 배치. 왼쪽 미리보기로 뒤집지 않는다. 최신 style.css 1.1.90 이후 구조를 우선한다.
- 카드 2장은 **가변 폭**, 카드 간 **12px**. 이미지 **정사각형(1:1)**, 비율 왜곡 없음. 과거 **196px 카드×2 / 이미지 84px** 고정 수치를 현행 가변 카드에 강제 적용하지 않는다.
- 각 상태 카드 순서: **상태명**, **표시 체크·제목 입력·T⌄ 글꼴 설정**, 아래 **왼쪽 아이콘 이미지 + 오른쪽 세로 5개 버튼**.
- 5개 버튼: **라이브러리 / 파일 / 클립보드 / 특수문자 / 초기화**. 각 **76×25px**, 세로 간격 **4px**, 기존 색상·테두리·Pretendard 글꼴·기능 유지.
- **미리보기 카드 너비 98px, 내부 미리보기 이미지 86×86px**, 아래 **▶ 실행 테스트**. 미리보기 자체와 실행 테스트를 생략하거나 임의의 곳으로 옮기지 않는다.
- 두 카드가 없는 단일 이미지·전용 액션에 가짜 상태 카드를 만들지 않는다. 그 액션의 기존 단일 미리보기/속성을 그대로 사용한다.
- 제목·이미지·배경의 **표시 속성 선택** 체크 규칙, 양 상태 독립·공유, 실제 이름 규칙 ON/OFF 이미지 쌍 예외 및 원본 값 보존은 **D200X-CURRENT-STATUS.md §3.1** 우선.
- 과거 ‘실행 테스트는 action-head에만’/‘취소·저장은 무조건 맨 아래’라는 일반 규칙보다 **현행 상태 카드 UI와 이번 상단 툴바 사용자 승인**이 우선한다.

### 3.3 번호·대표 이미지

- 누르기 번호 **1·2·3은 상단 아이콘 카드(2장 없는 경우 미리보기) 및 D200X 버튼 그리드 대표 이미지의 왼쪽 위 오버레이**로 표시. 탭 안에 번호를 붙이지 않는다.
- 대표 아이콘 선택은 **상단 이미지/미리보기 영역에서 체크 표시**로 구분하며, 기본은 **한 번 누르기**.
- 선택 대표가 비활성화되면 **활성화된 한 번 → 두 번 → 길게 누르기** 순으로 대체하되, 사용자의 저장된 대표 선택은 유지한다.
- 이 번호와 대표 마커는 **편집기 전용 오버레이**. 물리 D200X에 전송하는 PNG에 합성 금지.
- 실제 배지 위치·표시 기능은 최신 소스와 비교해 검증할 대상이며 **문서 작성으로 수정 완료를 주장하지 않는다**.

### 3.4 액션 고유 설정

- **효과음 재생 한정:** 파일 선택 아래에 `동작 / 페이드 / 페이드 시간` 한 줄, 다음 줄 `출력 / 음량`을 배치한다. 음량 슬라이더는 해당 액션의 재생 음량 0~100을 제어하며, 재생 중인 효과음에 미리 적용한 값은 저장/취소에 연동한다. 다른 액션 레이아웃에는 적용하지 않는다.

- 단축키 전환·프로그램 열기·페이지 선택 등 탭별 액션의 **기존 전체 필드**를 그대로 보여준다.
- 프리셋, 단축키 키보드/선택 입력, 경로 선택 버튼, 힌트, 제목 스타일, 저장/취소 등 기존 처리·너비·정렬 임의 생략/재설계 금지.
- 선택된 탭 아래의 아이콘·미리보기·제목·필드·상태 UI를 **같은 액션 기준으로 함께 변경**한다.

## 5. 보관 문서 충돌과 변경 경계

- **오래된 인스펙터 계약:** docs/archive/D200X-INSPECTOR-LAYOUT-CONTRACT-20261117.md. 당시 196px 고정 계약과 이후 가변 카드 예외가 공존한다. 최신 UI 전체에 과거 수치를 적용하지 않는다.
- **Key Up/Down 예외 이력:** docs/archive/D200X-KEY-DOWN-UP-ICON-EXCEPTIONS-20261117.md. 코드·실기 성공을 보증하지 않는 설계 이력이다.
- **과거 정적 UI 비교:** docs/evidence/gui/DeckForge-Inspector-Template.html. **1.1.88 준비 당시 예시**이므로 최신 카드 좌우·3탭·메뉴 배치의 근거로 단독 사용 금지.
- **활성 세부 계약:** docs/D200X-CURRENT-STATUS.md §3·§3.1; **실제 표시 기준:** app/streamdeck-editor/editor.js + style.css + index.html.
- 이번에 승인된 UI 변경은 기존 화면의 부분 변경이지 **메인/아이콘팩/노브/와이드/플러그인/프로필 레이아웃의 재설계 허가가 아니다.**

## 6. 앞으로의 문서·개발 작업 규칙

1. 새 채팅에서 사용자가 레이아웃을 다시 설명하게 하지 않는다. 기본 2문서 확인 후 **UI 작업이면 본 문서 해당 절만 추가 확인**한다.
2. 시안은 **최신 소스의 실제 카드와 미리보기 위치·크기·옵션**을 재사용한다. 다른 카드/가짜 필드·제목줄·구분선을 임의로 추가하지 않는다.
3. 수정 전 **보존할 영역, 바꿀 영역, 기존 코드와 승인 목표의 차이**를 구분한다. 불명확한 부분을 추측해 구현하지 않는다.
4. 승인된 작업 외의 소스 수정·커밋·빌드·브랜치 전환/생성·PR 병합 금지. 기존 데이터와 작동 기능 보호.
5. 확정된 UI 변경 시 **이 문서의 해당 절**, 구현·검증 상태가 바뀌면 **D200X-CURRENT-STATUS.md**의 해당 부분을 함께 갱신한다. 과거 이력은 보존한다.
6. **소스 점검 / 자동 검사·CI / Windows 빌드 / 실제 Windows·D200X 검증**을 각각 별도로 보고한다. 문서 정리를 기능 완성으로 표기하지 않는다.
