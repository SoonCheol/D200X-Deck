## 1.1.104 — Fusion 영어 이름 수집 도구 (2026-11-24)

- **수집 준비:** 명령 관리자에서 Python .py + Fusion 스크립트 .manifest 폴더를 다운로드에 안전하게 생성. 영어 Fusion에서 실행한 UI JSON을 별도 버튼으로 불러옴. 한국어 메뉴 순서 및 기존 버튼은 변경하지 않음.
- **결과:** 명령 ID별 영어 이름, 작업 영역/탭/패널/드롭다운 영어 라벨을 별도 저장. 명령 상세 영문명과 영어 이름 검색 지원. 한국어 캡처 오등록 차단 및 중복 이름 충돌 수 기록.
- **한계:** 아직 관리자 메뉴·실기 버튼의 전체 한영 전환은 구현하지 않음. 영어 Fusion 실제 수집, Windows 설치와 D200X 실기 확인은 별도.

## 1.1.103 — DeckForge 독자 플러그인 패키지·기존 SDK 호환 유지 (2026-11-24)

- **구현 범위:** Stream Deck 호환 `.sdPlugin` 폴더, `.streamDeckPlugin`/ZIP 설치는 그대로 유지. 독자 ZIP 기반 `.deckforgePlugin` 설치 파일과 `deckforge-plugin.json` 규격 v1 추가. 플러그인 탭의 **패키지 저장**은 유효한 `.sdPlugin` 폴더를 단일 `.deckforgePlugin`으로 저장하고 원본은 보존. 저장 위치는 Windows 파일 선택기를 통해 지정하므로 NAS/클라우드 동기화 디렉터리 수동 선택 가능.
- **검증·실행:** 전용 포맷/버전, 내부 SDK 매니페스트 ID·이름·버전 일치, 안전한 경로·ZIP CRC/용량/개수, 기존 동일 ID 덮어쓰기 방지. v1의 실행 런타임은 여전히 기존 Stream Deck SDK HTML/Node 호환 호스트를 사용한다. 독립 실행 SDK를 구현했다고 주장하지 않음.
- **Ulanzi 변환은 후속:** 현재 자동 변환 기능 없음. 미검증 Ulanzi 출처의 전용 패키지 설치 거부. API 변환·정적 검사·호스트 모의 실행·필요 시 실기를 통과해야만 패키징, 미지원 중 유용한 기능은 DeckForge용 자체 개발 대상으로 분류. 설계 문서 [`docs/DECKFORGE-PLUGIN-FORMAT.md`](./DECKFORGE-PLUGIN-FORMAT.md).
- **검증 상태:** GitHub 코드·테스트 파일·Windows 빌드 워크플로에 검증 단계 반영. Windows 빌드/실기 결과는 실제 성공 확인 후 별도 기록. 기존 사용자 데이터 자동 변환·원본 플러그인 폴더 변경·추가 수동 빌드 없음.
## 1.1.102 — 길게 누르기 해제 폴백·업데이트 빌드 비교 (2026-11-22)

## 1.1.101 — 누르기 3탭 편집 대상 격리·비동기 이미지 저장 보호 (2026-11-22)

- **보존/검증:** 기존 프로필·고정 버튼·대표 아이콘·드래그 동작 및 `BUG-010 pin-shadowed` 보존. 집중 회귀 테스트 추가. GitHub 자동 CI/Windows 빌드 및 사용자 D200X 실기는 결과 별도 확인.

## 1.1.100 — AI 도우미 최근 버튼 실행 진단 및 Windows 단축키 삽입 확인 (2026-11-22)

- **요청:** "방금 누른 키 잘 작동해?" 질문에서 한 번의 제한된 `action_check` 조회로 프로필·페이지·버튼·실행 단계별 사실만 간결히 보고한다.
- **단축키:** 물리 입력 ID를 단축키 IPC까지 전달하고, 해당 IPC에 한하여 Win32 `SendInput` 삽입 개수가 요청 개수와 같을 때만 Windows 입력 스트림 전달 성공으로 기록한다. 대상 프로그램의 실제 단축키 기능 실행은 확인하지 않는다.
- **프로그램·파일·폴더:** 기존 네이티브 도우미의 `focused/present/opened` 관찰일 때만 창 확인 성공. `launch-requested`와 Shell 열기 요청 완료만으로는 창 확인 미확인으로 분리한다. 기존 앱/폴더 제어 기능과 사용자 데이터는 유지한다.
- **개인정보·사용량:** 최근 세션 입력 128개 이내의 검증 결과만 사용, 단축키 조합은 허용 문자만 기록. 사용자 경로/로그 원문/비밀은 AI 입력에 포함하지 않는다. 기존 별도 조회 대신 진단용 한 번 조회를 사용한다.
- **검증:** 집중 회귀 테스트 및 Windows 빌드 성공과 실제 Windows/D200X 실기 검증은 별도로 보고한다.

## 1.1.99 후속 — 효과음 재생 속성창/음량 조절 수정 (2026-11-22)

- **배치:** 효과음 재생 액션에만 `동작 / 페이드 / 페이드 시간`, 다음 줄 `출력 / 음량`을 배치한다. 파일 선택과 출력 장치 설명은 유지하고, 다른 액션의 속성창은 변경하지 않는다.
- **음량:** 슬라이더 `input`을 0~100 값으로 미저장 편집에 반영하고, 같은 효과음 액션에서 재생 중인 HTML Audio(겹쳐 재생 포함)의 음량에도 반영한다. 페이드 진행 중의 목표 음량도 갱신한다. **취소**는 재생 중인 음량을 편집 전 값으로 되돌리고 **저장**은 변경값을 유지한다.
- **검증 범위:** 필드 순서/그룹 및 음량 변경·저장·취소의 집중 Node 테스트. 실제 Windows/D200X 효과음 출력과 CI/Windows 설치 빌드는 별도 확인한다.

## 1.1.99 — 누르기 3탭별 독립 아이콘·미리보기 표시 수정 (2026-11-22)

- **문제:** 대표 아이콘 누르기 종류와 현재 편집 탭이 다를 때, `displayItem`이 해당 탭의 실제 액션 대신 대표 액션을 고르는 경로가 있어 **Key Up/Down 카드, 제목/미리보기, 드래그 대상 표시**가 다른 탭의 이미지로 보일 수 있었다.
- **수정:** 물리 D200X 버튼·메인 그리드는 기존 대표 아이콘 선택을 그대로 사용한다. 일반 LCD 버튼 **속성창만** `inspectorDisplayItem`을 통해 현재 선택된 액션을 그리며, 각 탭의 서로 다른 `settings.keyPressIcons.up/down`, `stateTitles.first/second`, `keyBackgrounds` 저장은 기존 구조를 유지한다. Key Down을 별도로 등록하지 않았다면 Key Up으로 대체 표시하는 기본 동작도 보존한다.
- **관련 아이콘 도구:** `hotkey-switch` 상태 1/2 아이콘을 아이콘 라이브러리에서 선택할 때도 기존 독립 `sdkStateIcons.off/on`에 저장하도록 조건을 보완했다.
- **범위:** 일반 버튼의 해당 아이콘 조회 로직과 회귀 테스트만 수정한다. 탭/아이콘 카드의 레이아웃·위치·높이, 페이지 번호 전용 고정 탐색, 노브·측면·와이드·프로필 저장 구조와 기존 기능은 변경하지 않는다.
- **검증:** 3개 누르기 × Key Up/Down 6개 이미지 및 제목을 서로 다르게 지정한 경우의 모의 결과, 대표 아이콘과 속성창 선택 동작의 분리를 검사한다. Windows 빌드와 실제 D200X 확인은 별도로 기록한다.

## 페이지 번호 버튼의 고정 탐색 입력 (2026-11-22)

- **사용자 확정:** 전용 페이지 번호 표시 버튼은 **한 번 누르기 → 홈(루트 첫 페이지)**, **두 번 누르기 → 직전 페이지**, **길게 누르기 → 직전 프로필**로 고정한다. 일반 액션을 임의 등록하는 제스처가 아닌 *전용 탐색 입력*이다.
- **속성창:** 기존 페이지 번호·제목/아이콘/배경·일괄 관리 UI 보존. 세 가지 고정 탐색 동작만 **읽기 전용 문자열**로 표시하고 편집용 선택 목록/변경 이벤트를 만들지 않는다. 실행 테스트는 유지한다.
- **입력 판정:** 페이지 번호 버튼에만 짧게 누름 확정 대기 **300ms**, 길게 누름 **기존 650ms**를 사용한다. 첫 번째 누름 이후 300ms 내 두 번째 누름이 완료되면 직전 페이지 이동을 한 번만 실행한다. 길게 누름은 직전 프로필 이동 한 번만 실행한다. 기존 측면 버튼 추적·Key Logic·순차 동작 1초 중단·일반 3탭에 판정 변경을 적용하지 않는다.
- **프로필 왕복:** 이미 있는 `createPageVisitTracker().returnPrevious(state,'profile-history')`의 A↔B 토글을 재사용한다. 이동 이력이 없거나 이전 프로필이 삭제된 경우는 이동하지 않는다. 기존 사용자 저장 `indicatorDown/indicatorHold`는 소급 삭제하지 않고 전용 고정 입력에서만 적용하지 않는다.
- **와이드키:** 덱폴더 내부 **한 단계 상위로 이동**, 바깥 **기존 와이드 표시 모드 전환** 유지. 전체 페이지·프로필·덱폴더 관리, 다른 버튼 디자인·다른 액션 기능은 수정 범위 밖이다.
- **빌드 완료(1.1.98):** 기능 소스 커밋 `6751bf8cb3771ee25f8e8c11f02d7070c2a90b5c`, 버전 변경 커밋 `22fc05c24824a5fc368d6fc43aafad8cceeacd73`. 기존 앱 제어 입력의 격리 테스트가 새 상태 저장소/기존 종료 판정 함수를 누락해 첫 두 Windows 빌드에서 실패했으며, 테스트 환경만 `045dc34483fc4daf4cc82b03d329a1788bb9b420` 및 `3361f50a672cc7daa5ed74ea6a06a9e5c5dcb843`로 보완. 기능 실행 소스는 추가 변경하지 않음.

## 1.1.87 일반 백업 .dfjson 및 민감정보 사전 검사 (1.1.88 빌드 포함)

- 사용자 결정: 일반 백업 파일의 확장자를 `.json`에서 **`.dfjson`**으로 변경. 로컬 생성/복원과 Google Drive 업로드/목록/다운로드의 확장자·MIME·선택기 분기를 일치시킴. 기존 `.json` 전체 백업은 지원하지 않아도 된다는 승인에 따라 백업 경로에서 제외하며, 별도 OAuth JSON 및 개별 프로필 JSON 기능은 유지. 이전 파일은 자동 삭제하지 않음. `.dfjson`은 비암호화 평문이며 확장명만으로 보안이 강화되지 않음.
- 일반 백업 실행 시 저장된 프로필(활성·비활성), 템플릿, 물리 입력 등의 텍스트 필드에서 주민번호·전화·주소·이메일·카드·계좌·토큰/인증 필드 및 사용자 경로 의심을 로컬 메인 프로세스에서 검사. 원문은 반환/로그 저장하지 않고 종류·위치·건수만 표시. 모든 패턴을 포착하지 못하는 휴리스틱이며 검사가 불완전한 경우도 알림.
- 의심 항목이 있거나 검사 범위를 초과하면 공통 DeckForge 창에서 **취소 / 일반 백업 유지 / 암호화 백업** 선택. 암호화 백업은 결과와 관계없이 백업 형식 필드에서 언제든 선택 가능. 백업 파일 내용 자동 변조 없음. 원래 복원 전 암호화 안전 백업 및 비밀번호 절차는 이번 범위에서 변경하지 않음.
- 1.1.86 비밀번호 최소 길이 4자 변경은 기존 미푸시 커밋을 계승. Windows/CI/실기 검증과 브랜치 푸시/빌드는 사용자 별도 지시까지 보류.

## 1.1.82 Google Drive 일반 JSON 업로드 검증 오류 수정 (2026-11-21)

### 1.1.13 코드 반영 기록 (2026-11-19)

- 앱 버전 1.1.13. 종료 요청에 추적 ID를 부여하고 실제 `app.getVersion()`·메인 PID·프로필/페이지/폴더/슬롯·고정 키·인스펙터 dirty·hold 설정·물리 down/up/유지시간·IPC force·Close/Force 모드를 연결한다. 로컬 진단 로그는 `%APPDATA%\DeckForge\diagnostics\app-control-YYYY-MM-DD.jsonl`에 UTF-8 JSON Lines로 기록한다. 이 파일의 사용자 경로와 앱 정보는 공개 저장소에 올리지 않는다.

## 3. 사용자 승인 UI: 기본 골격·상태별 카드 (최신 예외 우선)

**기본 UI 고정**: 왼쪽 D200X 일반 키 13개·와이드 1개, 측면 버튼 2개, 노브 3개와 페이지 제어; 아래 인스펙터; 오른쪽 프로필·장치·설정·검색·기본 액션/플러그인 영역. 외부 앱 인스펙터/UI로 대체하거나 임의 재배치·폰트/버튼 높이 재설계 금지. 변경은 사용자 요청된 국소 범위만.

**기존 일반 키 인스펙터의 4영역 기본 원칙**(상태 카드가 없는 액션 등에 적용):
1. `.action-head`: 액션 경로·이름·도움말, 오른쪽 **▶ 실행 테스트**.
2. `.properties`: 대표 미리보기, 제목 및 전체 액션별 설정(복합 액션 포함). 동적 속성 완성 후 아이콘 영역 생성.
3. 아이콘 한 쌍: 일반/Fusion `Key Up → Key Down`, 실제 상태형 SDK `OFF → ON` 중 한 종류만; 저장한 반대 스키마의 값은 삭제 금지.
4. `.inspector-save-bar`: 기본은 하단 **취소 / 저장**. 대표 아이콘·제목·필드 값을 같은 시작선에 맞추고 숨겨진 필드 삭제·잘라내기 금지.

**2026-11-17 최종 승인 예외 — 상태별 독립 제목 카드가 실제 표시되는 일반 키**: 위 고정 196px 카드/4영역 규칙보다 **아래 사항 우선**.
- `.state-title-layout`은 최신 소스의 **왼쪽 OFF/ON 또는 Key Up/Down 가변 카드 2장 → 오른쪽 대표 미리보기(카드 너비 98px, 내부 이미지 86×86px)** 순서로 한 가로줄에 배치, 카드 간격 **12px**, 이미지는 정사각형 `aspect-ratio:1/1`, 공간에 맞게 자동 축소하되 비율 왜곡 금지. 과거 미리보기 왼쪽 서술은 최신 구현/사용자 승인에 우선하지 않음. 창 크기에 따른 양방향 스크롤/클리핑 여부는 GUI 실측 대기.
- 각 카드 **상태명 바로 아래**에 표시 속성 선택 체크박스(기존 제목 체크박스)·입력 placeholder `제목`·`T⌄` 글꼴 속성 버튼. 별도 ‘제목’ 라벨 없음. 위치와 크기는 유지하며 의미는 아래 §3.1 최신 계약을 따른다.
- 기존 1.1.4 제목 전용 구현: 제목 1/2의 텍스트·활성화·글꼴·크기·색·외곽선·정렬을 저장하고 체크 조합에 따라 공유. 실제 사용에서 공유 요구와 불일치 확인. **후속 구현은 §3.1 최신 계약으로 확장**하고 제목만 공유하는 옛 정책을 적용하지 않는다. 해제 시 기존 설정값 보존, 과거 항목 fallback, 실제 편집 시에만 설정 생성 및 dirty 갱신 규칙 유지.
- 스타일 프리셋은 양쪽 모두 기존 단일 전역 `deckforge-title-style-presets-v1` 공유. 같은 `T⌄` 재클릭 닫기, 다른 카드/바깥 클릭 시 `aria-expanded=false`. 각 상태 카드의 이미지 미리보기 역시 실제 D200X 합성기와 같은 제목·스타일 사용.
- 각 카드의 기존 **라이브러리/파일/클립보드/특수문자/초기화** 버튼 **76×25px**, 간격 **4px** 고정; Pretendard 기본 크기 보존.
- 상단 **▶ 실행 테스트** 위치 유지. **플러그인 속성 열기**는 상태 카드 위 왼쪽, **취소/저장**은 같은 툴바 오른쪽. **이 경우 하단 저장 바 위치 규칙 적용하지 않음.**
- 이전 고정 계약은 카드 한 쌍 196px×2+12px=404px, 이미지 84px, 값 시작선 196px 및 `--inspector-preview-width:98px`를 정의했지만 **최신 가변 상태 카드 예외에 우선하지 않는다**. 예외 외 일반 액션/노브/측면 버튼/와이드는 기존 구조 유지.
- 공통 체크박스 15×15px 및 값 열 정렬, 폴더 자동 종료 시간의 별도 필드/숫자 내부 ‘초’, 웹사이트 프로토콜(기본 `http://`, 체크 시 `https://`), 프로그램 실행 인수 독립 전달, Windows EXE/LNK/BAT/CMD 드롭 시 응용 프로그램 등록·아이콘/제목 자동 추출은 기존 동작 보존.

### 3.1 최신 승인 개발 계약 — 표시 속성 선택 체크박스 (2026-11-18, 1.1.5 코드 반영·실기 대기)

**정확한 의미:** 기존 카드의 '제목 체크박스'는 제목 표시만이 아닌 **버튼 표시 속성 선택 체크박스**이다. Key Up/Key Down 및 OFF/ON 카드에 동일한 규칙을 적용한다. 기존 레이아웃·체크박스 위치·크기는 보존한다.

## 4. Key Up/Down·상태형 아이콘의 예외 정책

- **일반 순간형과 모든 Autodesk Fusion 명령**: `Key Up` 기본, 물리 `Key Down` 누름 이미지. 놓으면 복귀. 이미지가 같으면 기존 축소 효과만 적용하며 이중 효과 금지. 속성창 미리보기 마우스 클릭은 **시각 시뮬레이션 전용**; HA 토글·명령·SDK `keyDown` 전송 금지.
- **실제 상태형**(HA ON/OFF, SDK `setState/setImage`, `multi-switch`): 상태 우선, Key Up에 OFF/기본 강제 복귀 금지. Fusion 전체 명령은 사용자 지정 무상태 예외. 일반 SDK 전체를 무조건 상태형 취급하지 않는다.
- **표시 전용** `indicator`, **와이드 특수 화면**은 일반 키 두 상태 이미지 정책 제외. `timer`는 카운트다운/문구, `logic`은 실제 Down/Up 판정, `open-app`의 hold(close/force)는 누름 시간을 보존. `hotkey-switch`의 내부 교대 상태 표시 정책은 후속 설계.
- **페이지·프로필·폴더 변경**(`previous/next/goto/profile/folder`)은 전환 뒤 새 화면 슬롯의 정상 이미지가 우선, 이전 눌림 상태 잔류 금지. `sleep`은 잠자기/깨우기 동작 우선.
- `multi`/`random` 등 일반 액션은 순간형 가능. `system-mute`나 `media`가 토글 명령이라는 이유만으로 실제 장치 상태를 추적한다고 가정하지 않는다. 노브 회전에 키 Up/Down 이미지를 임의 적용하지 않는다.
- **정책과 구현/실기 증거를 구분**. 예외 문서의 과거 “구현 전” 체크박스는 당시 스냅샷이다. 최근 Key Up/Down 카드 기능 코드·Windows 빌드 성공 기록은 본 문서에서 판단하되 물리 동작은 별도 확인한다.

## 5. 설정·자료 보존·플러그인 경로

- 현재 Windows Electron 사용자 데이터 루트는 **`%APPDATA%\DeckForge`**. 프로필은 `Profiles/profiles.json`, 직전 백업 `profiles.json.bak`; 이미지 데이터 URL은 `Resources/Icons/`에 SHA-256 중복 제거 파일로 분리 저장한다. 기존 localStorage 구성은 **사용자 승인에 따라 자동 이관하지 않으며** 삭제도 하지 않는다. 프로필 읽기 오류 시 빈 파일로 덮지 못하도록 저장 차단·사용자 알림 유지.
- 외부 아이콘팩 공통 라이브러리 `Resources/IconPacks/icon-packs-v1.json`, SDK 플러그인 공통 `Plugins/`. 구 `StreamDeck/IconPacks`·`StreamDeck/Plugins` 및 암호화 설정은 최초 안전 복사 후 **원본 보존**, 덮어쓰기/재등장 방지 로직 보호. 내장 팩은 앱 배포 리소스이며 사용자 JSON과 분리.
- 아이콘팩 가져오기 `.streamDeckIconPack`/ZIP/일반 이미지 폴더/`.sdIconPack` 폴더, 기존 원본 바이트 보존; 정적 144px 초과는 비율 축소, SVG는 안전 검사 후 PNG 변환. 대형 애니메이션 GIF/WebP를 임의 정지 이미지로 대체 금지. 압축 및 개별 이미지 용량·개수 검사 유지.
- Fusion 명령 캐시는 사용자가 지정한 이미지 우선, 정상 수신 이미지 우선, 연결 끊김 오버레이는 런타임 합성으로 **원본 이미지 불변**. 명령 식별은 단순 actionUUID 공통값이 아닌 `settings.pluginSettings.commandId` 기반, PC별 원본 Fusion 이미지/개인 데이터는 공개 GitHub에 올리지 않는다. Fusion add-in 건강 확인은 루프백 기반 `endpoint.json` + `/health`, WebSocket 연결과 실제 Fusion 실행 상태를 혼동하지 않는다.
- 파일/앱 드롭, HA 인증·기기 상태, Stream Deck HTML/Node SDK 플러그인·원본 Property Inspector·Fusion SDK의 기존 호환 경로는 보존. Node.js 호스트의 WebSocket 자동 프로토콜 검증 성공은 Fusion 실제 명령 실행/Windows UI/물리 키 성공이 아니다.
- 설치형(NSIS) 제거 시 **기본은 사용자 데이터 보존**, 명시적인 선택을 했을 때만 `%APPDATA%\DeckForge` 정리; 비대화형 제거는 보존. 다른 앱이나 구 폴더를 건드리지 않는다.
- 기본 UI 글꼴 **PretendardVariable.woff2** 13px, 보조 **NotoSansSymbols / NotoSansSymbols2**, 라이선스 동봉. 패키징 시 공식 바이너리 SHA 검증. 키 제목 `titleStyle.family='default'`은 내장 Pretendard, 사용자가 명시한 다른 글꼴은 보존. 네이티브 펌웨어 시계·정보 화면은 이 PNG 글꼴 변경 대상 아님.

## 6. 주요 기능·우선순위 및 보류

- Stream Deck 기본 **24개 액션 보존**, D200X 추가 18개와 HA 레거시/SDK 플러그인 경로 구별. 오른쪽 패널은 액션 그룹 + 별도 **작동하는 플러그인 탭**; 초기 HTML의 disabled만으로 미구현으로 판단 금지. `Virtual Stream Deck`은 **사용자 지시에 따른 개발 보류**.
- 기본 액션: Multi, Multi Action Switch, Random, Key Logic, 시스템/미디어/탐색/프로필/폴더. 일부 하위 조합·실제 앱/물리 입력 검증은 미완료. 물리 double/hold 시간 범위는 실기 근거 없이는 확정하지 않는다.
- 기본 액션 확장 24개 **후보**(기존 엔진 재사용 포함); 우선 8개: Windows 음량/음소거, 확대·축소, 스크롤, 실행 취소·다시 실행, 창 전환, 가상 데스크톱, D200X 밝기. 조절형 버튼·노브는 동일 `action.type/settings` 모델, 노브 단계 1/2/5/10 및 반전. 코드/모의 검증과 실제 Windows·D200X 반응은 구분한다.
- 폴더 최대 8단계, 신규 페이지 10개 제한(기존 10개 초과 데이터 삭제 금지), 고정 키는 다른 페이지 **빈 슬롯만** 상속·프로필별 격리. Auto Folder Exit은 **폴더 안에서 액션 실행 후** 0~60초, 0초 즉시 복귀. Smart Profile은 **기본 비활성, 편집기 최소화 중에만** 동작. 고정 상속 실시간 변경 공유·액션별 폴더 나가기 예외·전경 앱 실측 보완은 남아 있다.
- 물리 버튼/노브 페이지 이동 1회 뒤 무반응은 과거에 이미 디바운스/설정/상태 초기화 코드 보정함. **미착수 문제로 되돌리지 말 것**; 최신 설치본에서 재현될 때만 로그와 함께 국소 수정.
- 와이드 화면은 네이티브 시계/날짜·통계·노브 정보 모드 및 순환, CPU/RAM/GPU 겹침 등 사용자 보고와 후속 수정 기록이 있다. 모든 상태/버튼 1회 입력이 완전 해결됐다고 일반화 금지. 와이드 정보 슬롯에 일반 액션 드롭 금지, 노브/측면 버튼 우클릭 삭제 기능 유지.
- Fusion Command Manager는 Fusion 360의 실제 **메뉴 계층** 기준(스케치 → 솔리드 → 곡면 → 메쉬 → 판금 → 플라스틱 → 관리 → 유틸리티 → 자동화), 좌→우/위→아래 순서, 툴바가 아닌 메뉴 기준. 명령 아이콘 경합 및 드래그 동작의 국소 수정 기록이 있다. 실행 명령 성공 여부는 실제 Fusion 설치/애드인/버튼에서 별도 검증.
- 우선순위는 `docs/D200X-STREAMDECK-ROADMAP.md`의 계획과 최신 사용자 요청을 함께 따르되, 오래된 로드맵 체크박스가 최신 구현을 되돌리지 않는다.
