## 1단계 구현 범위
- app/streamdeck-editor/ai/: 독립 모델리스 창, 제한된 IPC, 공식 OAuth PKCE·nonce·state 및 ID 토큰 서명 검증, Windows safeStorage, 공개 models/Responses, SSE, 중지, 한도 안내, 로컬 암호화 대화 기록.
- 기존 편집기 오른쪽 검색 아래 AI 도우미 버튼. 기존 2열 폭 보존을 위해 먼저 독립 창으로 구성. 도킹은 별도 승인 및 GUI 검증 후.
- 개인용 단일 등록 계정의 로그인 및 재연결. 다중 계정/워크스페이스 선택 UI는 구현하지 않음. 새 계정 등록 지원은 추후 별도 검토.
- 프로필/로그/PC 정보 자동 전송 없음. 사용자가 지시하여 전송한 대화 및 체크한 읽기 전용 get_version 함수 결과만 전달. 함수 호출 1회, 추가 모델 호출 1회로 제한.
- 사용자 데이터 AI/connection.enc, AI/history.enc를 기존 프로필과 분리. 기존 프로필 저장/장치 실행 경로 무수정.
- ChatGPT 앱별 사용량/크레딧 관리는 계정 설정에서 확인. 실제 한도 초기화 시각 추정 금지.
- API 요청에 store:false, stream:true. 완료 이벤트 없으면 기록에 확정하지 않음. 오류 시 유료 API로 전환하지 않음.
- 참조: https://developers.openai.com/siwc/token-sharing-open-source/sign-in 및 /models-and-inference, /profiles-and-sessions, /preview-limitations. 이음오피스 코드 자체를 복사하지 않고 공식 문서 기반 별도 구현.

## 1단계 실기 결과 (2026-11-20)
- 1.1.42 Windows 통합 빌드 #755 성공. 사용자 직접 연결·대화·로컬 버전 조회 답변(1.1.42) 성공 보고. 함수 호출 완료 상태 표시 자체는 별도 미확인.
- 사용자 체크 완료: 새 대화·이전 대화 선택, 대화 삭제, 재실행 후 로그인 유지·기록 유지, 연결 해제·재로그인, AI 창 크기 조절. 응답 도중 중지는 미검증으로 기록.
- 1.1.43 본체/AI 입력란 텍스트 우클릭 및 AI 답변 복사 지원. 기존 D200X 버튼 우클릭 유지. 새 메뉴 실기 확인 대기. 원격 토큰 폐기/실제 갱신, 한도, 전체 기존 기능 실기까지 검증됐다는 의미는 아님. 2단계 미착수.

## 1단계 실기 확인
1. Windows 설치본에서 AI 도우미 열기/닫기·너비 조절, 기존 화면 유지.
2. 브라우저 승인, 모델 목록, 한국어 일반 대화, 응답 중지, 새 대화·기록 조회/삭제.
3. 버전 조회 함수 테스트 허용 체크 후 "DeckForge 버전을 로컬 함수로 조회해 줘" 요청. 실제 도구 호출 표시와 최종 답 확인.
4. 프로그램 재실행 후 연결 및 대화 기록 유지, 연결 해제/재로그인. 원격 폐기 미확인 별도 표시.
5. 기존 D200X 일반 키·노브·미저장 와이드 경고 정상 동작 확인.
6. 실제 API 한도/인증/함수 호출 결과를 사용자 실기와 구분해 기록. 2단계는 별도 사용자 승인 후 착수.

## 2단계 — 1.1.44 읽기 전용 환경 조회

- 기존 버전 함수에 inspect 함수 추가, 17개 조회 영역(section): profiles, page, actions, icon_packs, icons, start_apps, running_windows, device, recent_inputs, plugins, plugin_actions, ha, fusion, app_log, folder_log, usb_log, guide. 입력은 설정된 enum·1기반 프로필/페이지/폴더 경로·검색어·offset만 허용.
- 디스크 저장본 조회와 현재 화면 메타데이터를 구분하며 미저장 초안은 전송하지 않음. 페이지 키 목록에는 고정 키 적용과 예약 와이드 위치를 표시하고 노브 설정을 요약. raw 경로, 프로그램 인수, 텍스트 입력 본문, 인증 정보, 플러그인 비공개 설정, 원본 이미지 제외. 사용자 지정 이름 자체에 민감한 내용이 포함될 수 있으므로 명시적 조회 허용, 흔한 비밀 패턴 마스킹 적용(모든 개인정보 자동 제거를 보장하지 않음).
- Windows 조회는 고정된 Get-StartApps / Get-Process 대표 창 조회만 수행, 명령 문자열과 경로를 모델에서 받지 않음. 모든 설치 프로그램·모든 창의 완전한 목록은 아님. SDK는 설치 매니페스트, HA는 기존 내장 REST 설정과 지원 엔티티, Fusion은 기존 로컬 health 기준. 장치/로그는 실제 동작 성공과 구분. 앱/폴더 로그의 전체 원문과 범용 실행 추적 기능은 별도 과제.
- AI 패널에는 질문별 조회 허용, 조회 단계 표시, 응답 완료 시 API 요청 횟수·실제 응답 usage 토큰 합(있을 때만) 표시. 최근 8개 메시지/16,000자, 조회당 최대 3 API 요청·4 함수 호출, 결과 각 12,000자/전체 24,000자, 중복 및 금지 함수 차단, 필터/페이지네이션 및 요청 단위 캐시. 구독 차감량 산정이나 외부 앱 한도 추정 안 함.
- 1단계 사용자 확인: 1.1.43 우클릭 복사/붙여넣기 정상. 응답 도중 중지는 미검증. 2단계에 기존 기능 변경·파일 쓰기·실행 권한 없음.

### 2단계 최소 실기 시험
1. AI 도우미에서 이번 질문의 로컬 정보 조회 허용 체크 후 '프로필 목록과 현재 페이지에 등록된 버튼을 알려 줘'. 실제 저장 화면과 비교, 미저장/폴더 표시 구분.
2. 'D200X 연결 상태와 최근 입력을 알려 줘'. 기기 키를 누른 후 조회해 입력 번호와 시각 비교. 장치 입력은 실행 성공으로 단정하지 않아야 함.
3. '시작 메뉴에 등록된 메모장 AppID를 찾아 줘', '현재 열린 프로그램의 대표 창 상태를 알려 줘', '아이콘팩과 전등 아이콘을 찾아 줘'. 각 질문에 조회 체크.
4. 필요한 경우 '설치된 플러그인과 HA 내장 연결/Fusion 상태', '최근 프로그램/폴더 열기 로그의 실패 단계를 알려 줘'. SDK 전용 HA와 실제 성공 여부는 별도.
5. 조회 미허용 상태에서 로컬 상태를 묻거나 쓰기/PowerShell 실행을 요구하면 조회/실행하지 않는지 확인. 요청·조회 횟수 및 보고된 토큰 수 확인. 3단계는 사용자 승인 후 시작.
