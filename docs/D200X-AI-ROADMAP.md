## 1단계 구현 범위
- app/streamdeck-editor/ai/: 독립 모델리스 창, 제한된 IPC, 공식 OAuth PKCE·nonce·state 및 ID 토큰 서명 검증, Windows safeStorage, 공개 models/Responses, SSE, 중지, 한도 안내, 로컬 암호화 대화 기록.
- 기존 편집기 오른쪽 검색 아래 AI 도우미 버튼. 기존 2열 폭 보존을 위해 먼저 독립 창으로 구성. 도킹은 별도 승인 및 GUI 검증 후.
- 개인용 단일 등록 계정의 로그인 및 재연결. 다중 계정/워크스페이스 선택 UI는 구현하지 않음. 새 계정 등록 지원은 추후 별도 검토.
- 프로필/로그/PC 정보 자동 전송 없음. 사용자가 지시하여 전송한 대화 및 체크한 읽기 전용 get_version 함수 결과만 전달. 함수 호출 1회, 추가 모델 호출 1회로 제한.
- 사용자 데이터 AI/connection.enc, AI/history.enc를 기존 프로필과 분리. 기존 프로필 저장/장치 실행 경로 무수정.
- ChatGPT 앱별 사용량/크레딧 관리는 계정 설정에서 확인. 실제 한도 초기화 시각 추정 금지.
- API 요청에 store:false, stream:true. 완료 이벤트 없으면 기록에 확정하지 않음. 오류 시 유료 API로 전환하지 않음.
- 참조: https://developers.openai.com/siwc/token-sharing-open-source/sign-in 및 /models-and-inference, /profiles-and-sessions, /preview-limitations. 이음오피스 코드 자체를 복사하지 않고 공식 문서 기반 별도 구현.

## 1단계 실기 결과 (2026-11-20)
- 1.1.42 Windows 통합 빌드 #755 성공. 사용자 직접 연결·대화·로컬 버전 조회 답변(1.1.42) 성공 보고. 함수 호출 완료 상태 표시 자체는 별도 미확인.
- 사용자 체크 완료: 새 대화·이전 대화 선택, 대화 삭제, 재실행 후 로그인 유지·기록 유지, 연결 해제·재로그인, AI 창 크기 조절. 응답 도중 중지는 미검증으로 기록.
- 1.1.43 본체/AI 입력란 텍스트 우클릭 및 AI 답변 복사 지원. 기존 D200X 버튼 우클릭 유지. 새 메뉴 실기 확인 대기. 원격 토큰 폐기/실제 갱신, 한도, 전체 기존 기능 실기까지 검증됐다는 의미는 아님. 2단계 미착수.
