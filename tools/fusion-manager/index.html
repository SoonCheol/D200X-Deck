Fusion Command Manager 시제품 0.2

원본 아이콘 수집은 Fusion 360 및 FusionStreamDeck 애드인이 실행 중일 때 체크된 페이지의 명령만 가져와 매니저에 저장합니다. 페이지별 체크박스가 켜진 페이지만 등록합니다. 버튼을 다른 버튼 위로 끌면 삽입되고 뒤 명령이 밀립니다. 우클릭으로 예약 슬롯 지정·해제. 예약된 위치는 명령을 배치하지 않습니다.

추가 가능한 명령

명령을 클릭하면 마지막 비예약 빈 슬롯에 추가합니다.

Fusion 카탈로그는 수집 자료입니다. 일부 명령은 현재 설치된 Fusion 환경에서 실행되지 않을 수 있습니다. 추천 순서는 사용 통계가 아닌 기본 작업 흐름을 활용한 시제품 정렬입니다.
