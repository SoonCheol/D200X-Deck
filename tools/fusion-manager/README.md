# Fusion Command Manager — 독립 Windows 시제품 0.1

- Fusion 명령 카탈로그를 오프라인에서 열고, 페이지 5/5/3 버튼 배치로 보여줍니다.
- 버튼 드래그는 교환이 아닌 삽입 순서 이동입니다.
- 어느 버튼이나 우클릭으로 예약 슬롯을 지정/해제할 수 있습니다.
- 페이지별 등록 체크박스로 내보낼 페이지를 고릅니다.
- 프로젝트 JSON으로 저장/불러오기 가능하고, DeckForge 등록 JSON을 따로 생성합니다.
- 기존 DeckForge 'Fusion 360 명령 일괄 등록 JSON 가져오기' 메뉴를 그대로 사용합니다.
- 기존 d200x-fusion-batch-v1 명령 배열 형식과 하위 호환이며 선택적 layoutPages로 빈 슬롯 위치를 기록합니다.
- Fusion 실행 여부와 상관없이 저장된 카탈로그를 사용할 수 있습니다.

제한: 추천 순서는 현재 임시 명령 중요도 정렬이며 실제 인터넷 사용 빈도 통계가 아닙니다. 명령별 원본 아이콘 표시와 추천 점수 근거 표시는 후속 개선입니다. 실제 Windows/Fusion 실기 검증은 빌드 검증과 구분합니다. 폴더는 생성하지 않습니다.

## 영어 명칭 수집 (DeckForge 1.1.104)

- Fusion Command Manager에서 Python 수집기 폴더를 다운로드에 준비하며 기존 Fusion 설치는 변경하지 않습니다.
- 영어 Fusion에서 생성한 UI JSON을 명령 ID로 정규화하고 별도 파일에 저장합니다. 작업 영역·탭·패널·드롭다운 영어 명칭도 ID 기준으로 보관합니다.
- 기존 한글 카탈로그·실제 메뉴 순서·배치·버튼 제목 및 폰트는 변경하지 않습니다. 명령 상세의 영문명 조회 및 영문 검색만 연결합니다.
- 실제 영어 Fusion 수집은 사용자 PC 실기 확인 전입니다.

## 0.2 시각 개선 (2026-11-16)
- 여러 페이지의 5·5·3 배치 유지. 각 명령 버튼을 높이 116px로 키우고 48×48px PNG 원본 아이콘만 표시합니다. 원본이 없으면 아이콘 없음을 표시합니다.
- 원본 명령 아이콘은 DeckForge 기존 `%APPDATA%\DeckForge\fusion-command-icons\<명령ID>.png` 캐시에서 **읽기 전용**으로 가져옵니다. DeckForge와 Fusion 애드인의 파일을 변경하지 않습니다. 캐시가 없는 명령에 원·선·가위 등 임의 생성 그림을 사용하지 않고 '원본 아이콘 없음'으로 표시합니다.
- 버튼 이름은 최대 2줄. 잘려 보이는 명령 이름에 마우스를 대면 약 0.5초 후 툴팁: **첫 줄 한글 전체 이름, 둘째 줄 영문 전체 이름**. 영문명이 카탈로그에 없으면 `영문명 정보 없음`을 표시하며 ID를 임의 번역하지 않습니다.
- ⓘ 클릭 시 명령 ID·원본 이름·작업 범주·메뉴 경로 등의 정보 패널 표시. ⓘ는 드래그 시작을 방해하지 않도록 분리합니다.
- 작업 저장·등록용 JSON, 예약 슬롯·페이지 체크·순서 삽입은 이전과 같은 데이터 형식 및 동작을 유지합니다.
- 실제 Windows GUI/원본 아이콘 캐시 보유 환경은 사용자 확인 필요. 프로그램 실행 파일 자체의 고유 아이콘은 이번 변경 범위에 포함되지 않습니다.

## 원본 아이콘 정책 (사용자 요청)
- Autodesk Fusion 원본 아이콘 또는 이미 DeckForge에 정상 캐시된 원본 PNG 외에 명령 아이콘을 추정하거나 직접 만들지 않습니다.
- 캐시에 없으면 중립적인 '원본 아이콘 없음' 텍스트를 보입니다. 저장된 카탈로그에는 이미지 바이너리가 포함돼 있지 않으므로 모든 명령에 자동으로 원본 아이콘이 나타나는 것은 아닙니다.

## 원본 아이콘 직접 수집 (2026-11-16)
- **선택 페이지 원본 아이콘 수집** 버튼은 Fusion 360 및 공식 FusionStreamDeck 애드인이 켜져 있을 때만 실행합니다.
- Autodesk 공식 애드인의 로컬 발견 파일 `%LOCALAPPDATA%\\FusionStreamDeck\\endpoint.json`을 확인하고 `127.0.0.1:<포트>/health` 상태가 정상일 때 `GET /icon?commandId=<ID>&size=32`로 원본 이미지 자체를 요청합니다. **Fusion 명령 실행 POST는 절대 사용하지 않습니다.**
- 이미지 응답은 공식 서버가 반환한 PNG 또는 SVG 중 하나만 허용합니다. 768KB 크기 제한과 형식 검사를 거쳐 매니저 전용 Electron userData의 `original-fusion-icons` 폴더에 명령 ID로 저장합니다.
- 기존 DeckForge 원본 PNG 캐시는 **읽기 전용**으로 사용하며 이전 프로필과 캐시를 변경하지 않습니다.
- 버튼은 현재 등록 체크된 페이지에 있는 명령 ID만 모아 최대 3개씩 동시 수집합니다. 신규 저장 / 기존 캐시 / 원본 없음 / 오류 건수를 표시합니다. 미수집 항목은 '원본 아이콘 없음'으로 표시하며 임의 대체 그림을 만들지 않습니다.
- 외부 GitHub Actions 빌드에서는 Fusion GUI와 애드인이 실행되지 않으므로 실제 원본 아이콘의 수집 성공과 화면 렌더링은 사용자 PC에서 확인해야 합니다.

## Fusion 명령 수집·정리 (2026-11-16)
- 원본 **3,266개 카탈로그를 보존**합니다. 명령 삭제나 서로 다른 ID의 자동 통합은 금지합니다.
- 기본 표시 대상은 UI 카탈로그의 직접 툴바 명령과 툴바 드롭다운 명령입니다. 메뉴 전용은 검토 대상, 내부용 의심·미배치·정보 부족은 기본 숨김으로 분류하지만 전체 목록에서 언제나 복원할 수 있습니다. '숨김'은 실행 불가능하다는 판정이 아닙니다.
- 이전 `line/rectangle/...` 부분 문자열에 의한 가짜 사용 빈도 우선순위를 폐지하고 **Fusion 작업 영역→탭→패널→컨트롤 경로순**으로 자동 배치합니다. 실제 수집 경로가 없으면 기존 카탈로그 경로를 활용합니다.
- 동일한 한글 표시 이름이 여러 ID를 가진 경우 ⓘ 상세 정보에 다른 ID를 기록하며, 기능이 같다는 검증 없이 합치지 않습니다.
- 상세 정보의 **목록 표시**에서 자동 분류/기본 표시/검토 대상/숨김을 직접 선택할 수 있습니다. 덮어쓰기 가능한 사용 설정은 매니저 userData의 `fusion-command-visibility-v1.json`에만 저장되며 원본 카탈로그와 기존 프로젝트는 손대지 않습니다.
- Fusion 안에서 `tools/fusion-mcp/fusion-ui-inventory.py`로 수집한 `deckforge-fusion-ui-placements-v1/v2` JSON을 **Fusion UI 수집 JSON 반영** 버튼으로 불러올 수 있습니다. 수집 파일에서 확인한 ID를 기본 대상으로 승격하되 이전 스캔에 없다는 이유로 명령을 삭제하거나 자동 숨기지 않습니다. 사용자 배치 페이지도 자동 재생성하지 않으며, '추천 순서 자동 배치'는 명시적으로 누를 때만 작동합니다.
- 수집기 v2는 ID·이름·실제 UI 계층·컨트롤 순서 외에 직접 버튼/드롭다운/Split Button, 표시/활성 상태를 기록합니다. 상태는 수집 시점의 UI 정보일 뿐 실행 가능 여부에 대한 보증이 아닙니다.
- 제한: Fusion API 탐색 오류나 비활성 작업 영역은 누락 가능성이 있습니다. 실기 UI 수집은 사용자 Fusion 환경에서만 가능하며 GitHub Actions의 Node 테스트/Windows 패키징 성공만으로 현장 정확도가 입증되지는 않습니다.
