# Standalone drop probe
No DeckForge application files or user profiles are used. Native probe uses Windows PowerShell 5.1 STA and WinForms; Electron probe uses 45.2.1, as pinned in DeckForge Windows packaging. Extract the artifact, run the native .cmd and Electron executable separately. Label each test and drop Explorer EXE/LNK, Start pinned Win32, all apps Win32, pinned Store, all apps Store. Save both logs locally and redact private paths before sharing. No dropped program is executed. Native shell parsing names are recorded; explicit AUMID property extraction and virtual file stream decoding are not implemented in this initial probe. If WinForms does not expose COM IDataObject the log indicates that limitation. No GUI test is claimed by the build.
