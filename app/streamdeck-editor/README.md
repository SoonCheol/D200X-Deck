# Stream Deck 7.6.1 기반 D200X 편집기 — 독립 구현 시작점

## 실행

`app/streamdeck-editor/index.html`을 브라우저에서 열면 별도의 개발용 UI가 표시된다. 기존 `app/renderer/`를 불러오지 않는다. Electron 메인 프로세스/USB/D200X 실행 엔진과는 **아직 연결하지 않았다**.

## 이번 구현에 실제 포함된 기능

- D200X용 13개 일반 키와 1개 와이드 키의 그리드.
- 오른쪽 5개 범주 24개 기본 액션의 목록·검색·접기·펼치기.
- 액션을 키로 드래그해서 등록하거나 선택된 키에 클릭으로 등록.
- 단순한 동작별 속성 폼: 오디오 재생의 파일/동작/페이드/음량/출력(기본만), 타이머, 밝기, 웹사이트, 텍스트, 멀티미디어, 열기/닫기/앱 실행 등. 사용자 변경값은 독립 브라우저 저장소에 저장.
- 빈 키와 액션 등록 키의 별도 우클릭 메뉴. 폴더·다중 동작·Key Logic 생성, 액션 복사, 삭제 확인, 붙여넣기의 **일부** 구현.
- 페이지 추가와 페이지 간 전환.

## 미구현·불일치 (중요)

- 실제 Ulanzi D200X 통신·키 누름·실행 기능 **미연결**.
- 음원 재생 엔진, 페이드 지속 시간, 시스템 출력 장치 나열 및 오디오 모드의 실제 동작 **미구현**.
- 폴더/다중 동작/스위치/무작위/Key Logic 내부 편집 및 실행 **미구현**.
- 원본 아이콘과 픽셀 단위 정합성 **미검증**. 현재 목록 아이콘은 임시 문자다.
- 등록 키/빈 키의 우클릭 메뉴 일부는 **표시만** 하며 누르면 미구현이라고 알림. 메뉴 전체의 상태별 동작 미완성.
- 타이머 알림음, 앱 연결, 브라우저별 구체적 선택, 핫키 수집 UI, 아이콘 파일 선택, 프로필 관리, 노브와 측면 키 미구현.
- HTML 브라우저의 로컬 저장소는 실제 D200X의 설정/프로필 저장과 별개.
- 35개 원본 스크린샷의 실제 픽셀 비교 및 Windows에서 GUI 구동 검증은 아직 수행하지 않음.

## 원본 근거

`research/streamdeck/7.6.1/desktop/09-24-action-inspectors-observed.md`와 `research/streamdeck/7.6.1/desktop/local-reference/`. 구현 대상과 제한은 `AGENTS.md`를 참고한다.

이 디렉터리의 코드는 완제품이 아닌 **기존 Ulanzi UI와 분리한 최초 구현**이다. 사용자가 일치한다고 확인하기 전까지 원본과 동일하다고 주장해서는 안 된다.
