# Stream Deck 7.6.1 기반 D200X 편집기 — 독립 구현 시작점

## 실행

`app/streamdeck-editor/index.html`을 브라우저에서 열면 별도의 개발용 UI가 표시된다. 기존 `app/renderer/`를 불러오지 않는다. 브라우저에서 직접 열면 USB와 연결되지 않는다. **Windows Device Sync 프리뷰 EXE에서는 기존 D200X HID 통신 모듈과 연결하도록 수정했다(실기 미검증).**

## 이번 구현에 실제 포함된 기능

- D200X용 13개 일반 키와 1개 와이드 키의 그리드.
- 오른쪽 5개 범주 24개 기본 액션의 목록·검색·접기·펼치기.
- 액션을 키로 드래그해서 등록하거나 선택된 키에 클릭으로 등록.
- 단순한 동작별 속성 폼: 오디오 재생의 파일/동작/페이드/음량/출력(기본만), 타이머, 밝기, 웹사이트, 텍스트, 멀티미디어, 열기/닫기/앱 실행 등. 사용자 변경값은 독립 브라우저 저장소에 저장.
- 빈 키와 액션 등록 키의 별도 우클릭 메뉴. 폴더·다중 동작·Key Logic 생성, 액션 복사, 삭제 확인, 붙여넣기의 **일부** 구현.
- 페이지 추가와 페이지 간 전환.

## 미구현·불일치 (중요)

- D200X HID 연결/이미지 전송/키 이벤트 **코드 연결됨, 실기 미검증**. 액션 실행 기능 **미연결**.
- 음원 재생 엔진, 페이드 지속 시간, 시스템 출력 장치 나열 및 오디오 모드의 실제 동작 **미구현**.
- 폴더/다중 동작/스위치/무작위/Key Logic 내부 편집 및 실행 **미구현**.
- 원본 아이콘과 픽셀 단위 정합성 **미검증**. 현재 목록 아이콘은 임시 문자다.
- 등록 키/빈 키의 우클릭 메뉴 일부는 **표시만** 하며 누르면 미구현이라고 알림. 메뉴 전체의 상태별 동작 미완성.
- 타이머 알림음, 브라우저 선택, 핫키 수집 UI, 프로필 관리, 측면 버튼·노브의 실제 전송/실기 검증 미완료.
- HTML 브라우저의 로컬 저장소는 실제 D200X의 설정/프로필 저장과 별개.
- 35개 원본 스크린샷의 실제 픽셀 비교 및 Windows에서 GUI 구동 검증은 아직 수행하지 않음.

## 원본 근거

`research/streamdeck/7.6.1/desktop/09-24-action-inspectors-observed.md`와 `research/streamdeck/7.6.1/desktop/local-reference/`. 구현 대상과 제한은 `AGENTS.md`를 참고한다.

이 디렉터리의 코드는 완제품이 아닌 **기존 Ulanzi UI와 분리한 최초 구현**이다. 사용자가 일치한다고 확인하기 전까지 원본과 동일하다고 주장해서는 안 된다.

## 레이아웃 정비 (2026-11-14)

- 왼쪽 메인 상단의 기기/프로필 툴바를 제거하고 키 그리드를 위쪽에 배치. 창 높이가 커져도 버튼이 중앙으로 내려가지 않도록 상단 캔버스 높이를 제한하고 하단 속성창이 남은 공간을 사용.
- D200X 물리 측면 버튼 2개, 노브 3개를 키 그리드 바로 아래 표시. 키와 함께 독립 슬롯으로 선택 및 액션 드래그 등록 가능(실기 통신은 아직 미연결).
- 오른쪽 사이드바 왼쪽 위에 프로필 선택 드롭다운, 오른쪽에 D200X 표시/톱니바퀴를 두고 아래에 검색·키 목록 배치. 다중 프로필 관리와 설정 화면은 아직 미연결.
- 하단 제목 입력칸 바로 옆에 T⌄ 제목 속성 팝오버(표시·정렬·글꼴·크기·굵기·기울임·밑줄·색상·초기화) 배치. 변경한 값은 브라우저 임시 설정에 저장하며 키 미리보기의 텍스트 표현에 적용.
- 하단 아이콘 미리보기의 + 버튼으로 아이콘 라이브러리 창을, ▼ 버튼으로 원본 메뉴 모양을 표시. 파일 선택 및 간이 라이브러리 아이콘 적용과 임시 저장 가능.
- **아이콘 라이브러리의 아이콘 타일은 원본의 214/845개 전체 아이콘이 아니라 대체 심볼 샘플**이며, 원본과 동등한 고급 아이콘 편집기, 정식 라이브러리, 사용자 PC에서의 실제 화면 검증은 아직 미완성. 현재 버전의 화면을 원본과 완전히 같다고 평가하면 안 됨.


## D200X 하드웨어 화면 동기화 연결 (2026-11-14)

**현재 범위:** 실제 액션 실행은 여전히 미구현. 아래 항목은 코드 구현 상태이며, 사용자 Windows/D200X 실측 전에는 성공 처리할 수 없음.

- `transport.cjs`: 기존 `app/lib/deck.js`·`app/lib/page.js`의 D200X HID 송수신·페이지 전송만 사용, 재연결·최신 페이지 전송 큐. 기존 Ulanzi UI/액션 엔진 로드 없음.
- `preload.cjs`와 `main.cjs`: Electron IPC를 통해 renderer에서 이미지 배열을 보내고, 장치 연결 상태·버튼 이벤트·전송 오류를 수신. 기본 키 14개만 화면 데이터 전송 대상으로 허용.
- `device-sync.js`: 기본 버튼 13개 + 와이드 버튼 1개의 액션별 임시 기호 및 제목을 Canvas PNG로 그려 전송. 등록·수정·삭제·페이지 변경이 저장될 때 비동기 갱신. 기기 버튼 입력은 하단 상태 문구에만 표시, 실행 없음.
- 오른쪽 D200X 옆 상태점: 연결되면 초록색, 미연결이면 회색. 다른 소프트웨어(Ulanzi Studio 등)가 USB를 점유하면 연결 실패 가능.
- 측면 버튼 2개·노브 3개는 편집기에서 **가상 슬롯/선택**만 제공하며, 해당 위치의 디바이스 이미지 전송 기능은 확인되지 않았음. 실제 이벤트 인덱스와 동작별 대응은 실기 확인 필요.
- 화면 렌더는 임시 기호·폰트 기준. 원본 Stream Deck 아이콘 전체와 실물 색상/해상도 동등성 아직 미검증.

**Windows 시험:** 신규 Actions Artifacts `D200X-StreamDeck-Device-Sync-win-x64` 압축 해제, `D200X-StreamDeck-Preview.exe` 실행. Ulanzi Studio와 다른 USB 점유 앱은 종료하고, 오른쪽 상단 D200X 연결 표시 확인 → 액션 등록/제목 변경/삭제/페이지 전환 후 실제 D200X 화면 확인. 키를 누르면 프로그램 하단에 'D200X 입력 수신'이 표시되는지 확인. 반응이 없으면 표시된 상태/오류 문구를 기록. **액션이 실제 실행되지 않는 것은 계획된 동작**임.

**주의:** 이 장치 동기화 프리뷰와 이전 'UI-only' 프리뷰는 서로 다른 실행본이다. 이전 UI-only EXE에서는 USB가 연결되지 않는다.

## 공통 제목 글꼴·아이콘 변경 구현 (2026-11-14)

- **제목 글꼴:** 제목 표시, 정렬(좌/중/우), 글꼴(기본/맑은 고딕/Segoe UI), 크기(8~48), 굵게, 기울임, 밑줄, 색상, 기본값 복원을 설정·저장한다. 에디터 키 제목과 속성창 아이콘 미리보기에 반영하고, `device-sync.js`의 D200X 196px PNG 이미지에도 적용한다. 선택한 기본 폰트는 Windows에 설치된 글꼴에 영향을 받는다.
- **아이콘 변경:** `+`로 기존 임시 샘플 라이브러리 선택, `▼`에서 파일 설정/클립보드 이미지 붙여넣기/간이 '새로운 아이콘 만들기' 지원. 사용자 이미지(PNG/JPEG/WebP/GIF 첫 프레임)는 196px PNG로 정규화 후 현재 액션에 저장한다. 간이 아이콘 제작기는 문자와 문자/배경 색을 설정해 PNG를 생성한다.
- **공통 속성:** 각 액션 항목별로 독립 저장되며, 액션별 엔진이 아직 없어도 속성의 화면 이미지 반영은 가능하도록 연결했다. 브라우저 localStorage 한도 내 임시 저장이며 정식 프로필 파일 저장은 후속 코어 단계에 포함된다.
- **미검증/한계:** 실제 사용자 PC에서 폰트/아이콘 GUI 검증, D200X 화면 일치 여부, GIF 애니메이션, Stream Deck 원본 전체 아이콘 카탈로그/고급 아이콘 에디터는 미검증 또는 미구현. Actions 빌드 성공은 동작 성공 증거가 아니다.

## Stream Deck 7.6.1 원본 방식으로 제목/아이콘 레이어 교정 (2026-11-14)

- 원본 캡처 `research/streamdeck/7.6.1/desktop/screenshots/gui-evidence-761/title-options.png`와 Elgato 공식 `Custom Titles for Actions`, `Stream Deck SDK - Keys` 자료를 기준으로 제목 배치를 확인했다. **제목은 아이콘 위에 오버레이**되며 제목 위치는 좌/중/우가 아니라 **아래/가운데/위**이다. 원본에서는 신규 액션 제목 기본값은 공백이다.
- 기존 `left/center/right` 정렬값은 저장값 정규화 단계에서 `bottom/middle/top`으로 변환한다. 이는 과거 프로토타입 값의 오용을 수정하기 위한 호환 변환으로, 원본 UI의 수평 텍스트 정렬과 무관하다.
- D200X 화면용 PNG에서 제목 글꼴은 원본 Stream Deck 72px 키 기준의 설정 크기를 196px 전송 이미지에 비례 확대하여 그린다. 아이콘은 먼저 고정 좌표에 그린 후 제목을 겹친다. 제목이 커져도 아이콘 위치가 이동하지 않는다. 일반 키 편집기 화면은 **실제 전송용 PNG의 축소본**으로 표시한다.
- 사용자 파일 아이콘은 이미지 전체를 키 화면에 맞춰 종횡비 유지하여 표시한다. 기본 액션 아이콘은 여전히 임시 기호이며 정식 Elgato 그래픽 자산이 아니다.
- **검증 제한:** 이것은 문서/원본 캡처에 근거한 코드 변경으로, 실제 Stream Deck 앱에서 글꼴 크기를 조절하면서 화면 변화까지 직접 재현한 것은 아니다. D200X 실기에서 아이콘/글꼴 크기·제목 위치 비교 확인이 필요하다.
- 출처: https://help.elgato.com/hc/en-us/articles/360027958532-Elgato-Stream-Deck-Custom-Titles-for-Actions , https://docs.elgato.com/streamdeck/sdk/guides/keys/ .

## D200X 기본 Ulanzi 로고 복귀 방지 1차 수정 (2026-11-14)

- 기존 편집기에서는 `blank` 화면 모드 선택 후 주기적 CLK 명령이 멈춰 사용자 조작 없이 호스트 통신이 없을 수 있었다. OpenDeck D200X 등 공개 구현에서 D200X는 통신이 없으면 부팅 로고로 돌아가므로, 전송 후 **5초 무통신** 상태를 감지해 가벼운 유지 명령을 보내도록 했다.
- 현재 기기가 보고한 밝기값이 있다면 그 밝기값을 재전송한다. 보고받은 밝기가 없다면 **밝기를 임의로 바꾸지 않고** 기존 D200X 이미지 모드/시간 패킷 `2|||||24H|`를 전송한다. 이 대체 패킷은 넓은 화면의 미세한 깜빡임 가능성이 있으므로 실측 전에는 완전 무깜빡임을 보장하지 않는다.
- 전송 중에는 유지 명령을 건너뛰므로 페이지 ZIP의 HID 리포트 중간에 끼지 않는다. 연결 시도는 중복 실행하지 않으며 장치가 다시 연결되면 **편집기 조작 없이 마지막 14개 화면 이미지를 재전송**한다. 같은 세션의 기기 정보 응답은 중복 화면 전송을 유발하지 않는다.
- 연결/해제, 페이지 전송, 유지 명령, 오류는 Electron의 `app.getPath('userData')` 아래 `d200x-connection.log`에 기록(1MB 이상일 때 이전 로그로 회전). 정상 keepalive 로그는 대략 1분에 한 번만 남긴다.
- **코드/가짜 장치 시험과 실제 기기 시험은 별개**: Windows EXE가 통과하더라도 10분 이상 유휴 상태 화면 유지·화면 깜빡임·재연결 후 마지막 페이지 복원은 사용자 D200X에서 확인해야 한다.
